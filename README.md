# Journey to the Mysterious Island

A modular Python text-adventure game where the player explores a mysterious island, makes branching decisions, survives dangerous encounters, and works toward escaping the island.

## Features

- Five-chapter interactive story
- Branching player choices
- Shared game state across chapters
- Checkpoint and restart system
- Input validation
- Multiple outcomes
- Modular Python file structure

## Technologies Used

- Python 3
- Functions
- Dictionaries
- Conditional logic
- Loops
- Modular programming
- Command-line input/output
